# 42-Codexion

## thread lifecycle

```
Start Simulation
      │
      ▼
Try to get 2 dongles
      │
      ▼
Start Compiling
      │
      │  <-- time_to_compile -->
      ▼
Finish Compiling
      │
      ▼
Debug
      │
      │  <-- time_to_debug -->
      ▼
Finish Debugging
      │
      ▼
Refactor
      │
      │  <-- time_to_refactor -->
      ▼
Finish Refactoring
      │
      ▼
Immediately try to get 2 dongles again
```
